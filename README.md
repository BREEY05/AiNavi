# 智航AI协会网站

这是协会网站，可直接上传到服务器网站根目录访问。

## 页面结构

- `index.html`：首页
- `about.html`：关于我们
- `members.html`：社团风采
- `projects.html`：项目展示
- `activities.html`：近期活动
- `join.html`：加入我们
- `admin.html`：内部管理后台

## 资源与脚本

- `styles.css`：前台公共样式
- `admin.css`：后台样式
- `site-data.js`：默认内容、登录码、本地存储工具
- `main.js`：前台渲染、隐藏入口、详情弹窗
- `admin.js`：后台编辑、上传、保存、排序
- `assets/`：默认 Logo 与参考图资源

## 隐藏入口

右上角只有 Logo 图标，没有文字。连续点击 Logo 3 次后，会弹出内部验证码输入框。

验证流程：

```text
内部验证码：heyiwei
第二重登录码：qnmd
```

## 后台可配置

- 基础 Logo、协会名称、主题色
- 首页主视觉、标题、介绍、公告
- 关于我们页面文案、图片、统计卡片
- 社团风采：成员介绍（头像、头衔/职称、获奖情况）和活动风采（照片、文字），支持新增、删除、拖拽排序
- 项目展示图片、标题、分类、获得奖项、说明，支持新增、删除、拖拽排序
- 近期活动图片、标题、时间、地点、详情，支持新增、删除、拖拽排序
- 加入我们页面联系信息、招新信息、说明文案

当前静态版本会把修改保存在当前浏览器的 `localStorage` 中。正式公网多人维护时，建议后续接后端数据库或 JSON 文件接口。

## 上线部署

上传本目录下所有 `.html`、`.css`、`.js` 文件以及 `assets/` 文件夹到服务器网站根目录即可。
